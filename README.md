# NobleVeyra Advisory — GitHub Pages Site

This package recreates the approved dark-luxury NobleVeyra website direction in responsive HTML/CSS/JS.

## 1. Upload to GitHub
Upload every file and the `assets` folder to the root of your existing GitHub Pages repository. Replace the old site files when GitHub asks.

## 2. Edit your real links
Open `site-config.js` and replace:
- `strategyPaymentUrl`
- `intensiveApplicationUrl`
- `instagramUrl`
- `threadsUrl`
- `email`

You do not need to edit `index.html` just to change those links.

## 3. Founder imagery
The site intentionally uses `assets/tony-taylor-founder.webp` everywhere a personal image appears. That is the finalized NobleVeyra professional portrait created from the user's supplied reference photos.

## 4. GitHub Pages
Repository → Settings → Pages → Deploy from `main` / root.

## 5. Custom domain
Keep your existing GitHub Pages custom-domain DNS configuration. This package does not change DNS.

## 6. Important
The results section intentionally does NOT display fabricated testimonials. Replace the founding-client outcome cards only when you have verified client results.
